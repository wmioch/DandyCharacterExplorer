# Card artwork

These source screenshots contain the game's card artwork. CSS displays only the relevant card rectangles; the original downloaded images are retained unchanged. Artwork belongs to its original rights holders, including BlushCrunch Studio; these are not original or CC0 assets.

- `card-reference.png`: Well-Paced and Tech Savvy card faces, https://tiermaker.com/images/media/tierlists-2024/18209488/dandys-world-elevator-cards-16705464-1747600625.png (linked from https://tiermaker.com/categories/roblox-games/dandys-world-elevator-cards-16705464).
- `endurance-reference.webp`: Endurance card face in a gameplay screenshot, https://mumuglobal-res.fp.ps.easebar.com/file/69eec7d29bfd54502b657ecbE1Tmy95W03 (https://www.mumuplayer.com/blog/roblox-dandy-world-beginner-guide.html).

Retrieved and visually identified on 2026-09-21. Tech Savvy's pictured in-game wording says five seconds; the calculation uses five work units, as documented by the wiki. Debuffs use typographic UI symbols rather than claiming to reproduce game artwork.

September 22: Suppression also uses `card-reference.png`. `times-up-reference.jpg` is the unchanged thumbnail https://i.ytimg.com/vi/62sZC6xrvg8/maxresdefault.jpg from https://www.youtube.com/watch?v=62sZC6xrvg8. The TIME’S UP card was visually identified before use. All five CSS crops exclude the source white borders and each receives the same complete white CSS frame; no artwork or game text was generated. The direct Fandom TIME’S UP asset returned 403, so the accessible guide thumbnail was used.
